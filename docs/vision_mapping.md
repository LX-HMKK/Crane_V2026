# Crane 视觉模块映射规则

## 豆子 → 目标数字

取货区 ①–③ 号位通过豆子相机识别豆子种类，内部映射为要搬运到的数字：

| 豆子种类 | 目标数字 | 放置区货箱 |
|----------|----------|------------|
| 黄豆     | 1        | 贴有数字 1 |
| 绿豆     | 2        | 贴有数字 2 |
| 白芸豆   | 3        | 贴有数字 3 |

配置位置：`configs/vision.yaml` 的 `mapping.bean_to_digit`。

## 数字 → 放置区

数字相机识别放置区 ④–⑧ 号位侧面的数字 1–5，再反向查表：

- 数字 1 在哪个放置区 → 黄豆该去的位置
- 数字 2 在哪个放置区 → 绿豆该去的位置
- 数字 3 在哪个放置区 → 白芸豆该去的位置

数字 4、5 所在货箱为空箱，识别结果可显示但不参与任务生成。

## 辅助线分区规则

辅助线位置保存在 `configs/vision.yaml` 的 `lines` 字段，可在 `scripts/main.py --ui` 中拖动调整。

### 豆子相机（取货位 ①–③）

两条竖线 `bean.left_x`、`bean.right_x` 将画面分成三列：

| 检测框中心 x 范围 | 取货位 |
|-------------------|--------|
| `cx < left_x`    | ①      |
| `left_x <= cx < right_x` | ② |
| `cx >= right_x`  | ③      |

### 数字相机（放置区 ④–⑧）

- 横线 `digit.horizontal_y` 分隔前排（4、8）和后排（5、6、7）。
- 后排两条竖线 `digit.left_x`、`digit.right_x` 分隔 5/6/7。
- 前排用两条竖线的中点分隔 4/8。

| 位置 | 中心条件 | 放置区 |
|------|----------|--------|
| 前排 | `cy < horizontal_y` 且 `cx < midpoint` | ④ |
| 前排 | `cy < horizontal_y` 且 `cx >= midpoint` | ⑧ |
| 后排 | `cy >= horizontal_y` 且 `cx < left_x` | ⑤ |
| 后排 | `cy >= horizontal_y` 且 `left_x <= cx < right_x` | ⑥ |
| 后排 | `cy >= horizontal_y` 且 `cx >= right_x` | ⑦ |

> 严格 `<` 的边界语义：检测框中心恰好落在竖线上时，归入右侧区域；落在横线上时，归入后排区域；落在前排中点上时，归入 ⑧ 号区。若实际场地方向相反，只需在 UI 中调整 `horizontal_y`，代码不做方向硬编码。

## 缺失与重试策略

1. 连续采集 `scan.frames` 帧（默认 5）。
2. 每帧分别对豆子相机和数字相机做推理。
3. 按辅助线把每个检测框归入对应区域。
4. 每个区域保留**置信度最高**的检测结果。
5. 扫描结束后：
   - 若 3 个取货位和数字 1/2/3 所在放置区全部存在 → 生成 TASK。
   - 任一区域缺失或出现重复数字 → 记录原因，主程序重试 `max_retries` 次；仍失败则不发送非法 TASK 帧。

## 输出帧

视觉 → 下位机：

```text
BB 66 p1 p2 p3 1B 1A
```

- `p1`：① 号取货位（黄豆/绿豆/白芸豆）应去的放置区编号
- `p2`：② 号取货位应去的放置区编号
- `p3`：③ 号取货位应去的放置区编号
- 放置区编号范围：4–8
